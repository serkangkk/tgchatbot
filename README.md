# Telegram Karakter Sohbet Botu 

Bu bot, OpenAI GPT-4 kullanarak belirli karakterlerle sohbet etmenizi sağlar.

## Kurulum

1. `pip install -r requirements.txt`
2. `.env` dosyasına API anahtarlarını yaz
3. `python bot.py` ile başlat

## Komutlar
- `/start` – Sohbete başla
- `/karakter <isim>` – Karakter değiştir
